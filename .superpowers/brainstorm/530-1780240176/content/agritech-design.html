AgriSense — Monitor de Agricultura de Precisión

Aplicación demo · IoT + Automatización · FastAPI + React + PostgreSQL

Concepto

Un agricultor de precisión maneja múltiples zonas de cultivo (invernadero A, campo exterior B). Cada zona tiene sensores IoT que reportan humedad del suelo, temperatura, humedad ambiente, pH y luz. Un motor de reglas evalúa condiciones y dispara acciones: activar riego, alertar helada, notificar pH anómalo. El dashboard muestra todo en tiempo real.

Entidades del Dominio

Core
  • Zone — parcela/invernadero, cultivo, ubicación
  • Sensor — tipo (temp, humedad, pH, luz), zona, unidad
  • Reading — valor, timestamp, sensor_id
  • Rule — condición (metric > X), acción, activa/inactiva
  • Alert — regla disparada, timestamp, acknowledged
Soporte
  • User — login, rol (admin/operador)
  • RuleAction — qué hacer: alertar, activar relé, email
  • ZoneGroup — agrupación lógica de zonas

Funcionalidades

Core
  1. Dashboard general con status cards por zona
  2. Vista detalle de zona con gráficos time-series
  3. Tabla de sensores con último valor y estado
  4. Motor de reglas evaluando cada N segundos
  5. Historial de alertas con filtros
Demo
  1. Script que genera datos mock realistas cada 3-5s
  2. Dashboard se actualiza en tiempo real (polling/SSE)
  3. Reglas pre-cargadas que se disparan visiblmente
  4. Toggle para pausar/reanudar simulación

Stack Técnico

Infra

  • Script simulador integrado

Flujo Demo — Lo que se vería en vivo
  1. Login → Dashboard con 3 zonas: Invernadero Tomates, Invernadero Lechugas, Campo Exterior Maíz
  2. Cada zona muestra cards con último valor de sensores y estado (verde/amarillo/rojo)
  3. Script mock inyecta lecturas cada 3s — los gráficos se mueven solos
  4. Regla pre-cargada: "SI humedad suelo < 25% → alerta riesgo sequía"
  5. A los ~15s de demo, la humedad simulada baja del threshold → aparece alerta en el dashboard
  6. Usuario hace clic en la alerta, la marca como acknowledged, ve el historial
